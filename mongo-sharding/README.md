# Кластер MongoDB с шардированием (Задание 2)

## 🚀 Быстрый запуск

Все компоненты инфраструктуры, инициализация кластера и наполнение тестовыми данными запускаются одной командой.

1. Откройте терминал в корневой папке проекта.
2. Дайте права на запуск всем скриптам автоматизации:
   ```bash
   chmod +x scripts/*.sh
   ```
3. Запустите главный управляющий скрипт:
   ```bash
   ./scripts/run_all.sh
   ```

## 🛠 Что делает автоматизация
Скрипт `run_all.sh` пошагово выполняет следующие действия:
1. Запускает 4 контейнера в фоновом режиме (`configSrv`, `shard1`, `shard2`, `mongos_router`).
2. Инициализирует конфигурационный сервер (`config_server`).
3. Настраивает и запускает сервера шардинга (`shard1_set` и `shard2_set`).
4. Подключает оба шарда к роутеру `mongos` и включает шардирование для базы данных `somedb`.
5. Создает шардированную коллекцию `helloDoc` с хэшированием по полю `name`.
6. Генерирует и записывает **1000 тестовых документов**.
7. Выводит финальный отчет о распределении данных между шардами.

## 📊 Проверка распределения данных
Если вам нужно повторно проверить, сколько документов физически находится на каждом из шардов, запустите отдельный скрипт проверки:
```bash
./scripts/check_shards.sh
```

## 🧹 Очистка проекта
Чтобы полностью остановить контейнеры и удалить все созданные тома (volumes) с жесткого диска, выполните:
```bash
docker compose down -v
```
